# Chart APIs

## High-level charts

- `LineChart` from `@kamod-ch/charts/line`
- `AreaChart` from `@kamod-ch/charts/area`
- `BarChart` from `@kamod-ch/charts/bar`
- `PieChart` from `@kamod-ch/charts/pie`
- `ScatterChart` from `@kamod-ch/charts/scatter`

Common cartesian props:

- `data`
- `xKey`
- `xScale`
- `height`
- `width` or `initialWidth` + `responsive`
- `showGrid`
- `showLegend`
- `tooltip`
