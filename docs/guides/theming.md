# Theming

Charts use semantic CSS variables:

```css
--chart-1
--chart-2
--chart-3
--chart-4
--chart-axis
--chart-grid
--chart-tooltip-background
--chart-tooltip-foreground
--chart-tooltip-border
```

Tokens are compatible with Kamod UI and Tailwind CSS v4 variables. Avoid hardcoded colors in chart code.
