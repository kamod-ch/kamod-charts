## Orientation and reference lines

Vertical bars (default) use a categorical X axis and numeric Y axis. Horizontal bars swap those roles: values extend along X and categories along Y.

Reference lines follow chart coordinates, not data column names:

- `referenceLine.x` draws a vertical line at a value on the horizontal axis (numeric thresholds on horizontal charts).
- `referenceLine.y` draws a horizontal line at a value on the vertical axis (numeric thresholds on vertical charts, or a category string such as `"Mon"` on horizontal charts).
