## Built-in chart a11y

All high-level charts accept `title` and `description`. Line, scatter, and pie charts are keyboard-focusable.

<div class="not-prose my-6 overflow-visible rounded-xl border border-border bg-card p-4">
  <LineChart
    data={halfYearMetrics}
    xKey="month"
    xScale="point"
    series={[{ key: "revenue", label: "Revenue", color: chartColors.primary }]}
    height={220}
    initialWidth={640}
    responsive
    showGrid
    tooltip
    title="Accessible revenue chart"
    description="Monthly revenue for the first half of 2024."
  />
</div>

## Data table alternative

`@kamod-ch/charts/accessibility` exports `DataTable` and `buildChartDescription`.

<div class="not-prose my-6 overflow-x-auto rounded-xl border border-border p-4">
  <DataTable
    caption="Monthly revenue sample"
    columns={[
      { id: "month", header: "Month", accessor: "month" },
      { id: "revenue", header: "Revenue", accessor: "revenue" },
      { id: "customers", header: "Customers", accessor: "customers" },
    ]}
    data={halfYearMetrics}
  />
</div>
