## Copy-paste imports

```tsx
import { LineChart } from "@kamod-ch/charts/line-chart";
import { BarChart } from "@kamod-ch/charts/bar-chart";
import { useSynchronizedCartesianSelection } from "@kamod-ch/charts";
import "@kamod-ch/charts/theme/tokens.css";
```

Use `format={{ locale: "de-CH", timeZone: "Europe/Zurich" }}` on cartesian charts for consistent tooltips. Lift selection with `useSynchronizedCartesianSelection` when two time series use different sampling.

`hiddenSeriesIds` and `onHiddenSeriesChange` on `LineChart` keep the chart in sync with your own legend UI.

## Adapter contract

Map your dashboard DTO to chart rows (`date`, numeric metrics, category keys). Keep backend-specific field names outside the chart components.
