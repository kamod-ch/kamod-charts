# Changelog

## 0.1.0 - Unreleased

Initial release candidate.

### Added

- Core `Chart`/`ChartRoot`, SSR-safe responsive sizing, SVG surface, plot area, theme tokens.
- Scales, domains, axes, ticks, grid.
- `LineChart`, `ScatterChart`, `AreaChart`, `BarChart`, `PieChart`.
- Low-level series primitives.
- Tooltip, legend, crosshair, live region primitives.
- Data-table accessibility alternative.
- Reduced-motion and performance helpers.
- Tree-shakeable subpath exports.

### Not yet complete

- Browser-level accessibility tests.
- Full docs site.
- Advanced tooltip collision handling.
- Advanced downsampling and scatter spatial indexes.
